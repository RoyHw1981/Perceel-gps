Perceel GPS – iPhone webapp

Gebruik:
1. Upload alle bestanden uit deze map naar een webhost (bijv. GitHub Pages, Cloudflare Pages of Netlify).
2. Open de website in Safari op de iPhone.
3. Tik op Delen > Zet op beginscherm.
4. Open 'Perceel GPS' vanaf het beginscherm.

De app gebruikt openbare PDOK-diensten:
- PDOK Locatieserver voor adreszoeking
- PDOK Kadastrale Kaart / BRK voor perceelgeometrie

Uitvoer:
- RD X/Y (EPSG:28992)
- GPS/WGS84 latitude/longitude
- CSV-export

Let op: openbare kadastrale geometrie is indicatief en niet geschikt als juridische grensreconstructie.
